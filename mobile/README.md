# Merkez Мобильное Приложение (React Native + Expo)

Полноценная мобильная версия складской и кассовой системы с функциями терминала сбора данных (ТСД) и беспроводного сканера для компьютера.

---

## 🚀 Как запустить на телефоне

### Вариант 1: Мгновенный запуск через Expo Go (Android / iPhone)
1. Установите приложение **Expo Go** на телефон из Google Play или App Store.
2. В корне проекта или в папке `mobile` выполните команду:
   ```bash
   npm run mobile
   # или внутри папки mobile:
   npx expo start
   ```
3. В терминале появится **QR-код**:
   - На **Android**: откройте приложение Expo Go и нажмите **Scan QR code**.
   - На **iPhone**: откройте стандартную камеру и наведите на QR-код.
4. Приложение сразу откроется на телефоне!

---

### Вариант 2: Сборка готового Android APK файла
Чтобы собрать автономный установочный `.apk` файл для раздачи сотрудникам:
```bash
cd mobile
npx eas build -p android --profile preview
```

## 📱 Функционал мобильного приложения

### 1. 📦 Склад и остатки (`WarehouseScreen`)
- Синхронизация в реальном времени с облачной базой **Supabase**.
- Поиск по названию, штрихкоду, артикулу.
- Фильтры по категориям и критическим остаткам (товары, которые заканчиваются).
- Быстрое изменение цен и остатков (+ / -).
- Создание нового товара (автогенерация штрихкода или мгновенное сканирование камерой).

### 2. ⚡ Аппаратный сканер штрихкодов (`ScannerModal`)
- Нативное сканирование камерой через `expo-camera` со всеми форматами (EAN-13, EAN-8, Code 128, QR и др.).
- Включение вспышки (фонарик для темных складских помещений).
- Тактильная вибрация (Haptics) при успешном считывании.
- **4 режима работы:**
  1. **Товар (Терминал):** считывает штрихкод → открывает карточку товара с остатками и ценами.
  2. **Для ПК (Gun mode):** считывает штрихкод → мгновенно передает на экран компьютера в CRM.
  3. **Касса (POS):** сразу добавляет товар в открытый чек продажи.
  4. **Ревизия (Инвентаризация):** непрерывный быстрый пересчет позиций.

### 3. 📡 Режим «Сканер для ПК» (`PCGunScreen`)
- Телефон превращается в замену физического сканера-пистолета.
- Передача данных по каналу **Supabase Realtime** с задержкой **< 50 мс**.
- Журнал переданных штрихкодов со статусом доставки.

### 4. 🛒 Мобильная касса / POS (`POSScreen`)
- Формирование чека продажи со сканера или из каталога.
- Изменение количества, скидки, выбор способа оплаты (Наличные, Карта, Перевод).
- Проведение продажи с автоматическим списанием товара со склада.

### 5. 📋 Журнал операций (`OperationsScreen`)
- История приходов (поступлений от поставщиков) и расходов (списаний/продаж) в реальном времени.

### 6. 🛠 Сервис и Ремонты (`RepairsScreen`)
- Просмотр заказов на ремонт, привязка мастеров, изменение статусов («В ремонте», «Готов», «Выдан»).
